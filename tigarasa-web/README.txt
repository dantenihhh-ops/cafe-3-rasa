TIGA RASA — WEB PELANGGAN
=========================
Cara menjalankan (tanpa XAMPP):
1. Buka folder "tigarasa-web" di Visual Studio Code (File > Open Folder).
2. Install ekstensi "Live Server" (Ritwick Dey).
3. Klik kanan index.html > "Open with Live Server".
4. Tambahkan nomor meja di alamat, contoh:  http://127.0.0.1:5500/index.html?meja=04

Coba di HP (WiFi yang sama dengan laptop):
- Cek IP laptop (Windows: buka CMD, ketik ipconfig → IPv4 Address, misal 192.168.1.10)
- Buka di browser HP:  http://192.168.1.10:5500/index.html?meja=04

Coba tampilan HP di laptop:
- Tekan F12 di Chrome > klik ikon HP (Toggle device toolbar) > pilih iPhone / Pixel.

Halaman:
- index.html    Menu / Dashboard
- pesanan.html  Konfirmasi Pesanan
- status.html   Catatan / Status Pesanan
- bantuan.html  Bantuan (panggil waiter, minta bill)
